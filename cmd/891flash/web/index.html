891flash

Flash FT-891 MAIN / panel / DSP firmware from the browser over WebSerial. Chrome/Edge or Firefox 151+. Runs offline.

1 Firmware folder

Pick the folder with your AH065 firmware files (.SFL, .bin, .dat).

2 Decode SFL → BIN

Choose a firmware folder first.

3 Patches (optional)

Bundled patches load automatically; add a folder for your own .json patches.

4 Patches (optional)

Tick any patches to apply. Independent patches stack (applied top-to-bottom); conflicting or wrong-firmware patches fail before flashing.
No patches loaded — pick a folder in step 3.

5 Serial port

Connect the radio's CAT (Enhanced) USB port, then select it.

6 Flash

Dry run is OFF — Flash will ERASE and WRITE the selected target.

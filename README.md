# 891flash

An open-source toolkit for flashing **Yaesu FT-891** firmware and applying
community firmware patches — from your browser or the command line, on Windows,
macOS, Linux, and the Raspberry Pi.

> ⚠️ **This repository contains code generated by AI.** It was produced with the
> assistance of an AI coding tool and reviewed by the author. Read the code before
> you run it, and understand that flashing firmware carries risk (see below).

> **No Yaesu firmware is included here.** These tools operate on the official
> firmware **you download from Yaesu** and keep on your own machine. The repo and
> every release contain only original code and patch metadata.

---

## What's in the box

| Tool | What it does |
|------|--------------|
| **`891flash`** | A browser-based flasher. Run it and it serves a local web app (WebSerial) that walks you through decode → patch → flash for the MAIN, PANEL, and DSP boards. Bundled patches load automatically. |
| **`ft891flash`** | A headless command-line flasher (no browser needed) — ideal for a Raspberry Pi. |
| **`ft891patch`** | Applies a JSON firmware patch to your own `.bin` or `.SFL`, verifying SHA-256 before and after. |
| **`ft891customlogo`** | Turns a 92×16 PNG into a boot-logo patch (or splices it directly) — no firmware needed to generate the patch. |

Plus the **patches** themselves (JSON), their **source code**, and docs on the
patch format and how to write your own.

## Quick start (from a release)

1. Download the zip for your OS/arch from [Releases](https://github.com/fventuri/891flash/releases) and extract it.
2. Get the official FT-891 firmware from Yaesu and unzip it into a folder (it
   contains files like `AH065_M_V0110.SFL`, `AH065_P_V0101.SFL`).
3. Run **`891flash`** (double-click, or `./891flash` in a terminal). Your browser
   opens the flasher.
4. In the app: point step 2 at your Yaesu firmware folder. The **bundled patches
   are already listed** in step 4 — tick any you want (e.g. the voltmeter). Pick
   the serial port, follow the on-screen power-on instructions, and flash.

See [`docs/QUICKSTART.md`](docs/QUICKSTART.md) for the full walk-through, including
the headless command-line path (`ft891patch` + `ft891flash`) for a Raspberry Pi.

> **Requirements.** The browser flasher needs Chrome/Edge or Firefox 151+ (WebSerial).
> The USB adapter is the radio's CAT (Enhanced) port — a Silicon Labs CP210x.
> ⚠️ Flashing firmware can render a radio inoperable. Use at your own risk.

## Build from source

One Go module, four commands. Requires Go 1.21+.

```sh
git clone https://github.com/fventuri/891flash
cd 891flash
go build ./...                       # builds all four tools
go build -o 891flash ./cmd/891flash  # just the browser flasher
```

Cross-compile (no cgo needed):

```sh
CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -o 891flash.exe ./cmd/891flash
CGO_ENABLED=0 GOOS=linux   GOARCH=arm64 go build -o 891flash     ./cmd/891flash  # Raspberry Pi
```

Releases (zips for linux/amd64, linux/arm64, windows/amd64, darwin/arm64, plus a
`SHA256SUMS.txt`) are built automatically by GitHub Actions on a `v*` tag —
see [`.github/workflows/release.yml`](.github/workflows/release.yml).

## Patches

Each patch is a small JSON file containing **only the mod author's own bytes**
(new code plus the offsets that redirect to it) and SHA-256 fingerprints of the
official firmware it targets — never any Yaesu firmware. It's applied to your own
image, and the tools refuse to apply it to the wrong firmware version.

Independent patches can be **stacked** (applied together). See
[`patches/README.md`](patches/README.md) for the catalog and
[`docs/CREATING_A_PATCH.md`](docs/CREATING_A_PATCH.md) to write your own.
